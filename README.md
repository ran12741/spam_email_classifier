Spam Email Classification Using Machine Learning

Project Overview

This project classifies email messages as Spam or Ham (Not Spam) using Machine Learning.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- TF-IDF Vectorization
- Multinomial Naive Bayes

Features

- Predicts whether an email message is Spam or Ham.
- Uses TF-IDF to convert text into numerical features.
- Uses a Machine Learning model for classification.
- Provides a simple web interface using Streamlit.

Installation

Install the required libraries:

pip install -r requirements.txt

Run the Application

streamlit run app.py

Project Files

- "app.py" — Web application
- "main.py" — Machine Learning code
- "email.csv" — Dataset
- "requirements.txt" — Required libraries
